# PayBuddy AI

AI assistant that helps freelancers create invoices, send smart payment reminders, and get paid faster with PayPal.

## Features
- Create invoices in seconds
- AI generates payment reminders
- Pay securely with PayPal
- Dashboard for paid / pending payments

## Built With
PayPal API, OpenAI, JavaScript, HTML, CSS, Python

## How it works
1. Freelancer creates invoice
2. AI writes a polite payment reminder
3. Client pays via PayPal link
4. Freelancer gets paid faster
